# SAR 散射点引导目标检测

研究问题：预测散射点的位置，能否通过引导可形变卷积采样，稳定改善 SAR 目标检测？

本仓库于 2026-10-27 建立。已完成 FAIR-CSAR 检查与 `faircsar_local_v1` 数据处理/划分冻结；服务器数据检查、DCNv2 GPU 前向和梯度检查已通过。用户报告 E00 短训练与断点恢复测试通过；第一版完整 E00 协议和初始化已锁定，正式训练尚待执行。旧工程保留在上级目录，不能直接把历史指标当作本项目的对照结果。

## 目录

- `configs/`：模型、训练与数据配置。
- `splits/`：固定的数据划分名单及生成规则，不保存图像。
- `scripts/`：数据检查和 E00 训练入口；独立评估待实现。
- `src/`：后续模型修改；E00 当前使用固定版本的安装包。
- `records/`：精简实验记录与结果表，可提交 Git。
- `EXPERIMENTS.md`：实验协议、对照组和执行顺序。

本地可将数据放在 `data/`，运行输出放在 `runs/`，备份权重放在 `checkpoints/`；这些目录默认被 Git 忽略。

## 开始训练之前

1. 阅读 `records/DATA_FREEZE_2026-10-27.md`，了解类别疑点隔离、边界规则及基准范围。
2. 使用 `splits/faircsar_local_v1/` 的冻结记录，通过 `scripts/materialize_dataset.py` 在训练服务器重建数据；禁止重新随机划分。
3. 明确 YOLOv8s 上游来源、许可证及具体版本或提交，迁入必要代码。
4. 在远程 GPU 环境验证 PyTorch、torchvision 和 DCN 算子兼容性，记录依赖版本。
5. 跑通少量数据的训练、验证、权重保存和恢复流程，再提交可复现的代码与配置。
6. 按 `EXPERIMENTS.md` 开始完整实验。

服务器环境与 E00 短训练命令见 `records/E00_SETUP_2026-10-28.md`。先验证短训练，不要将数据构建完成理解为训练框架已经验证。

已通过上述流程后，按 `records/E00_FULL_PROTOCOL_V1.md` 启动完整 E00。full 入口会校验冻结配置、数据 manifest 和预训练权重 SHA-256。

## 版本和备份

- Git 保存源代码、配置、划分名单、环境说明和精简实验结果。
- 不提交数据集、权重、完整运行输出、访问令牌或 SSH 私钥。
- 每次完整训练使用唯一实验编号，记录干净工作区的 Git commit；有未提交修改时先提交，或另存可恢复的补丁并注明。
- 远程 GPU 服务器只作为执行环境；日志和权重应同步至本地或独立持久存储，并记录路径及 SHA-256。
- GitHub 远程仓库：<https://github.com/lxnancy22/git>，远程名称为 `origin`。已合并其原有初始提交，本地项目说明替换通用 README。
- 代码提交后使用 `git push` 同步；远程服务器使用 `git clone` / `git pull` 获取版本。数据和权重仍需独立备份。
