## 统一边界规则

1. 将源水平框还原成 xyxy，与图像 [0,1]×[0,1] 区域求交，再编码为 cx/cy/w/h。保留正面积交集，Detect 和 Pose 使用逐字符相同的五列框标签。
2. 不重新排序九点。在图内（包含 0 与 1 边界）的坐标保持不变，第三维设 1；图外点存为 (0,0,0)，只作为无效占位，不产生坐标监督。
3. 第三维是标签有效性，不能解释为实际散射点的物理可见度。有效点为 1，图外为 0；不存在把图外点挪到边缘形成伪真值的操作。
4. Pose 数据由 `[9,2]` 改为 `[9,3]`，每行 32 列；纯检测显式输出每行 5 列。所有点辅助对照组都采用此统一定义，kobj 损失因此可能生效，其权重需在训练配置中统一记录。
5. 图像像素保持不变，不旋转、不缩放、不重新编码。原始数据和已有 test 文件均不改写。

这一版的框定义是“图中可见的水平框交集”。标签几何和测试子集均经过明确派生，结果不能当作未修改官方数据上的成绩。

训练和验证只从原 trainval 的 11959 张图中分出。固定种子 20261027，目标验证比例 20%；按原始大图前缀成组，在 5000 个固定随机候选中根据图像数及五类目标数平衡选择，不参考模型结果或 test 表现。

各主集合五类均有样本。主集合总计 14660 张图、85280 个目标。有效数据中 9396 个目标的框执行了精确求交（包含不足一像素的边缘变化），29 个图外关键点设为无效；未因边界问题额外删除图像或目标。

全量源 PNG 计算 SHA-256，未发现字节完全相同的 PNG。三份主集合之间原始大图组、图像文件名及 PNG 内容哈希均无交集。

重要限制：不同大图可能覆盖相同城市/经纬度，训练、验证和测试存在相同地区的不同次成像。这是原始大图分组对比，不是地理区域完全独立的泛化评估；文件名推断不能替代完整地理覆盖和官方元数据核验。

## 冻结记录与使用

- `splits/faircsar_local_v1/`：固定名单、逐图来源与原始/派生标签哈希、原始图像哈希、统计及校验文件。由 Git 管理，不包含图像和标签数据本体。
- `configs/faircsar_local_v1_policy.json`：数据处理规则。
- `data/faircsar_local_v1/`：可供训练的 Detect / Pose 数据目录及各自 `data.yaml`，不提交 Git。
- 原始数据内容指纹：`942fbd8429296fb3fefa1cc5b47206aa8741190b7493d4817ad73763ea5f323a`，基于排序后的来源路径、每份原标签 SHA-256 和每张原 PNG SHA-256。
- 本地图像采用硬链接以节省空间；硬链接共享文件内容，源图与派生图均应作为不可变输入使用。远程可按磁盘情况使用 hardlink、copy 或 symlink 模式重建。

训练服务器只需准备相同源图像及原始 23 列标签，再从冻结记录重建：

```bash
python scripts/materialize_dataset.py --root /absolute/source/FAIR-CSAR-Full-Pose-Ordered --freeze splits/faircsar_local_v1 --output /absolute/datasets/faircsar_local_v1 --image-mode hardlink
```

命令默认核对原图和原标签哈希，重新生成标签并校验派生标签哈希。输出必须是新目录；只有 `BUILD_COMPLETE.json` 存在才表示完整构建成功。自动生成的 `data.yaml` 使用重建机器上的绝对路径。

固定数据版本后，训练不再各自筛选样本；加载器应读取全部冻结样本。环境搭建阶段仍需实测固定框架加载后的样本、目标及有效点数，发现差异时修正加载流程并记录，不能静默改变冻结名单。
