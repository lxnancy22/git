# 数据划分

此目录仅保存图像相对路径名单、划分元数据和生成规则，不保存数据本体。

正式版本放在独立子目录。`faircsar_local_v1/` 是已冻结版本，包含 `train.txt`、`val.txt`、`test.txt`、`quarantine.txt`，每行相对于任务数据根目录；两种任务使用相同路径名单。隔离名单只用于追溯，不交给训练器。

同时记录数据集名称/版本、子集、场景分组依据、生成脚本与种子、每集合图像数和目标数、跨集合重复检查结果，以及三份名单各自的 SHA-256。尽可能保存原始场景到切片的映射。

`manifest.csv` 保存每张源图/源标签、派生 Detect/Pose 标签的 SHA-256。`SHA256SUMS` 校验冻结包本身。版本一旦冻结不覆盖修改，后续调整使用新版本目录。

冻结目录在 `.gitattributes` 中禁用文本换行转换，确保 Windows 与 Linux 的检出内容字节一致，校验值不会因 CRLF/LF 自动转换而变化。
